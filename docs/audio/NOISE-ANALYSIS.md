# Полный анализ шума динамика (Redmi 10C / fog, mainline 7.1.5)

Дата: 2026-09-24. Статус: шум локализован до внешнего усилителя (aw87xxx);
остаточная причина — выход кодека WCD937x, который усилитель усиливает.

## 1. Симптом

- ВЧ-шипение (энергия в основном 3–16 кГц), слышно **поверх музыки**.
- В покое, при **включённом** PA, — тихий постоянный шум; при `mode=off` — тишина.
- **Не зависит** от цифровой громкости `RX_RX2 Digital Volume` (проверено на 84/64/44/0)
  → источник находится **после** цифровой ручки (аналог).
- Спектр шума **идентичен** при поднятом и опущенном тракте кодека — источник один,
  подъём тракта лишь повышает уровень.

## 2. Эксперименты и локализация

| эксперимент | результат | вывод |
|---|---|---|
| `echo off > .../0-0058/mode` (PA off) | шум пропадает | источник — **PA или его вход** |
| тракт кодека поднят + тишина | шум **громче** | добавляется шум **выхода кодека** |
| `RX_RX2 Digital Volume` 84→44→0 | шум не меняется | шум **после** цифровой ручки |
| питание кодека 1.8 В + нагрузка 650/10 мА | без изменений | не питание |
| перебор `RX HPH Mode` (6 режимов) | без изменений | не class-H |
| poke `0x30A5`, `0x340F` | `0x340F` меняет **уровень** (биты 2–7), не mute | цифровой mute там нет |
| poke `0x3128` (AUX-PA) | тест недействителен (поток завершался) | нужен `pcm-hold` |

## 3. Приведено к вендору (сверено по коду/дампам)

- **SoundWire**: `iface`-клок = RX-макро; HCTL/div2; форма кадра **50×16 + SSP=6**
  (вендорский enable-путь); порты `rx_frame_params_khaje`; форсированный re-init;
  `pm_runtime_forbid`.
- **WCD937x**: таблица reg-дефолтов сверена построчно (расхождений 2 — поправлены);
  AUX-путь; class-H/flyback/bias; `AUX_GAIN_*`/`AUX_DSM_*`; `RX HPH Mode` (исправлена
  таблица enum); `AUX PATH Mode` (бит 6 `DIGITAL_CDC_PATH_MODE`); DEM-dither выключен.
- **Mute/unmute RX3**: добавлен аналоговый (AUX-PGA bit7) на `POST_PMU`/`PRE_PMD` —
  дал **заметное** снижение щелчка и шума.
- **PA aw87xxx**: профиль Music = вендорские runtime-значения (регистр-в-регистр,
  кроме динамического `0x60`).
- **Питание кодека**: `regulator_set_voltage(1.8V)` + `regulator_set_load(650/10 мА)`.
- **Микшер**: сверен с Android (статический `tinymix`, 2509 контролов) — релевантные
  контролы совпадают, включая строки enum.
- **Стабильность**: защита от ACK-underflow; `hung_task_panic`/`panic` в init; debugfs
  в init; покер регистров `wcd937x-reg`.

## 4. Что НЕ совпадает / отсутствует

1. **ACDB** (Audio Calibration DataBase) — в Android грузится userspace-HAL
   (`libacdbloader`+`libaudcal` → `/dev/msm_audio_cal` → ADSP). У нас отсутствует;
   DSP и кодек работают на «номинальных» значениях.
2. **Громкость DSP (ASM volume)** — в mainline-стеке API нет вообще; отсюда
   наблюдение «у нас громче, чем в Android».
3. **Monitor-цикл PA** (динамический vmax/шумовые ворота) — у нас статический профиль.
4. **Цифровой RX_MUTE** (вендорское болеро-событие `WCD_BOLERO_EVT_RX_MUTE`) —
   vendor-specific, в mainline-драйверах (wcd937x/wcd938x) отсутствует.

## 5. Вывод

Шум = **выход кодека WCD937x (AUX)**, усиленный **внешним PA aw87xxx**.

- В покое: PA включён и усиливает шум своего входа → тихий постоянный шум.
- Во время игры: на входе PA присутствует шум аналогового выхода кодека → шипение
  поверх музыки.

Вендор в этих же условиях чист, потому что:
- включает PA **только на время воспроизведения**;
- выход кодека у него **откалиброван через ACDB** (у нас калибровки нет).

## 6. План

- **A. PA выключать в покое** (как в Android) — убирает тихий постоянный шум.
  Реализация: обёртка `play` (PA on → играть → PA off) или привязка к состоянию DAPM.
- **B. ACDB** — единственный оставшийся известный путь к «как в Android». Требует
  порта загрузчика калибровки (парсер `.acdb` + APR-транспорт) либо захвата
  ioctl-пейлоадов из Android и replay.
- **C. Громкость DSP (ASM volume)** — устранит разницу по громкости.
